# 리바이브모션 (ReviveMotion)

출장마사지·홈타이 **방문 관리** 안내 정적 사이트. 외부 의존성 없이 Node 표준
라이브러리만으로 HTML 을 찍는다(`npm install` 할 것이 없다).

```
npm run regions   # data/regions.json 재생성 (경계 자료가 갱신될 때만)
npm run build     # → dist/
npm run check     # 빌드 결과 자체 검사 — 실패가 있으면 종료코드 1
npm run serve     # dist 를 띄워 눌러 본다
node scripts/simil.mjs   # 구 페이지끼리 본문이 얼마나 겹치는지
```

## 지역 단위

**시도 15 → 시군구 150** 두 단계다. 행정동 2,228곳은 **페이지로 만들지 않고**
구 페이지 안에 이름으로 적는다. 동마다 쪽을 내면 내용이 구 페이지를 쪼갠 판에
그치는 얇은 쪽이 2천 장 생긴다.

커버리지는 `yeomim.f.jieumweb.com` 의 `tk_region` 을 그대로 떠 왔고(`data/_yeomim_coverage.tsv`),
셋을 고쳐서 쓴다. `scripts/build-regions.mjs` 를 돌리면 고친 내역을 화면에 찍는다.

| | 고친 것 | 왜 |
|---|---|---|
| ① | 모(시) 버킷 12개 제거 | `경기/고양시` 와 `경기/고양시 덕양구` 가 함께 있었다. 같은 땅인데 쪽이 둘 생긴다 |
| ② | `인천 서구` → `서해구` | 2026 개편 명칭. 경계 자료가 정본이다 |
| ③ | `경기 부천시 오정구` 보충 | 부천시를 다루면서 한 구만 빠져 있었다 |

★광주와 전남은 갈라 둔다. 경계 자료는 `전남광주통합특별시` 로 합쳐 두었지만
행정 명칭이 바뀌어도 검색어는 따라오지 않는다.

## 꼭 지키는 것

**① 전화번호는 `telBtn()` 으로만 찍는다.**
안심번호 옆에 **예약 문의**가 늘 붙은 버튼이어야 한다(지시 사항).
번호를 문자열로 직접 쓰는 곳이 있으면 `npm run check` 가 잡는다 —
버튼 밖 맨 번호, 라벨 빠진 버튼, 버튼 없는 쪽을 각각 센다.
본문 산문에서는 숫자를 적지 않고 '안심번호'·'예약 문의 버튼'으로 가리킨다.

**② 같은 주소면 같은 HTML 이다.**
`new Date()` 가 결과물에 들어가면 안 된다. RSS `lastBuildDate` 를 빌드 시각으로
두면 같은 내용인데도 파일이 매번 달라진다 — 글 발행일에서 뽑는다.
검사 방법은 두 번 빌드해서 `dist` 해시를 견주는 것이다(검사 12종은 HTML 만 본다).

**③ 수정일을 거짓으로 올리지 않는다.**
빌드마다 전 페이지 lastmod 를 오늘로 찍으면 "매일 310쪽이 바뀌었다"는 거짓
신선도 신호가 된다. 날짜 자리를 `@@LM@@` 로 비운 채 본문 해시를 내고, 해시가
지난 빌드와 같으면 그 날짜를 그대로 쓴다(`data/lastmod.json`). 그래서 **이 파일을
저장소에 함께 커밋한다** — 지우면 다음 빌드에서 전 쪽이 오늘로 찍힌다.

**④ 후기·평점·사람 사진을 쓰지 않는다.**
받은 적 없는 평가를 숫자로 만들면 거짓이다. JSON-LD 에 `aggregateRating`·`review`
를 넣지 않는다. 주소가 없는 방문 사업이라 `LocalBusiness` 도 쓰지 않는다
(address 를 요구하는데 지어내면 그 자체가 허위 신호다).

**⑤ 얇은 조합 페이지를 만들지 않는다.**
구 × 코스(150 × 8 = 1,200쪽)를 만들지 않는다. 구가 달라져도 코스 설명이 같아서
전부 도어웨이가 된다. 코스는 시도 단위까지만 내려간다.

**⑥ 다른 사이트와 문장이 겹치지 않는다.**
단어만 바꾼 문장도 중복으로 본다. 확인 방법은 두 가지다 —
문장 완전일치 비교, 그리고 지명·숫자를 가린 **골격** 비교.

## 색인

`robots.txt` 에 `Yeti` · `Yeti-Mobile` · `*` 세 그룹을 **같은 규칙으로** 적는다.
Yeti 그룹을 따로 두면 Yeti 는 `*` 그룹을 통째로 무시한다. `Crawl-delay` 는 적지
않는다 — 적는 순간 네이버가 그만큼 쉬엄쉬엄 긁는다.

`sitemap-latest.xml` 은 최근 14일 안에 **실제로 바뀐** 쪽만 담는다. IndexNow 통보
스크립트가 이 파일을 먼저 읽어 바뀐 주소가 회차 상한을 먼저 가져간다.

IndexNow 키 파일은 사이트마다 달라야 한다. 남의 키를 함께 서빙하면 403 이 떨어진다.
